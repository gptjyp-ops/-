처음 사용하는 클랜원

사진을 올리고, 숫자를 확인하고, 한 번에 저장해요.

01 우리 클랜으로 들어가기

클랜장이 보내준 초대 링크를 여세요. 입장 코드가 필요하면 클랜장이 알려준 코드를 입력합니다. 주소에 비밀번호를 적거나 공개 톡방에 관리 비밀번호를 보내지 마세요.

02 사진 준비하기

스킬, 알 소환, 탈것 소환, 녹색 물약 화면을 준비하세요. 알·탈것 합성 수량도 등록하려면 각각의 합성 화면을 추가로 캡처합니다. 합성 화면에는 ‘선택됨’ 숫자가 보여야 해요.

03 처음에는 저장 없이 연습하기

사진 인식 연습 화면은 사진을 읽고 결과를 보여줍니다. 클랜 기록을 저장하지 않으니 여기서 먼저 테스트하세요. 일반 인식부터 사용하고, 실패하면 호환 인식으로 같은 사진을 다시 시도합니다.

연습 체크

내가 들어갈 클랜의 링크를 받았나요? 네 가지 화면을 구분할 수 있나요? 합성 사진과 소환 사진이 서로 다른 사진이라는 점을 확인했나요?

캡처 사진 올리기

휴대폰 파일도, PC에서 복사한 캡처도 사용할 수 있어요.

01 파일 선택

해당 재화 탭에서 ‘스킬 화면 올리기’처럼 사진 올리기 영역을 누릅니다. 휴대폰 사진첩 또는 PC에서 캡처 파일을 선택하세요. JPG, PNG, WEBP 파일을 최대 10MB까지 사용할 수 있습니다.

02 PC에서 붙여넣기

캡처를 복사하고 해당 사진 칸을 선택한 뒤 Ctrl+V를 누릅니다. 또는 ‘복사한 캡처 붙여넣기’를 누르세요. 브라우저가 클립보드 권한을 요청하면 사진 읽기에 필요한 권한을 허용합니다. 안 되면 캡처를 PNG로 저장해 파일 선택으로 올려보세요.

03 사진 모양을 유지하기

수량, 소환 레벨, 현재 단계가 보이게 캡처하세요. 숫자 위에 낙서하지 않고 원본 캡처를 사용하면 좋습니다. 임의로 잘라낸 사진이나 흐린 사진은 인식하기 어려울 수 있어요. 사진을 올린 뒤 읽는 동안 기다려주세요.

연습 체크

녹색 물약 사진을 연습 화면에서 골라 읽어보세요. 미리보기의 숫자와 결과를 비교하세요. 이 연습만으로 클랜 기록이 저장되지는 않습니다.

스킬·알·탈것·물약 확인

합계보다 먼저 원본 사진의 숫자와 비교해요.

01 스킬·알·탈것 소환 화면

보유 재화, 소환 레벨, 현재 단계를 확인합니다. 개별 스킬·펫·탈것 카드의 레벨과 소환 레벨을 혼동하지 마세요. 예를 들어 Lv.32와 0/23이 보이면 소환 32레벨, 현재 0단계입니다. 0은 미입력이 아닙니다.

02 ‘최대’ 표시

소환 버튼 옆 정보 아이콘 아래에 ‘최대’가 보이면 소환 100레벨로 처리하고 ‘승천대기’로 표시합니다. 100레벨 전에는 ‘승천불가’로 표시합니다. 개별 장착 카드가 100레벨이라는 뜻은 아닙니다.

03 녹색 물약 두 가지 화면

기술 트리 전체 화면과 클랜 기술 상세 화면 모두 사용할 수 있습니다. 왼쪽 위의 녹색 시험관 옆 수량만 읽습니다. 빨간 물약, 보석, 기술 진행 퍼센트는 녹색 물약 수량이 아닙니다.

04 k 단위와 소수점

3.3k = 약 3,300개 / 24k = 약 24,000개 / 2.73k = 약 2,730개. 게임의 축약 표시이므로 ‘약’으로 표시합니다. 원본이 3.3k인데 결과가 33k 또는 33,000이라면 소수점 인식 오류입니다. 저장 전에 다시 인식하고 원본을 운영자에게 보내주세요.

연습 문제

원본 3.3k → 결과 33,000개: 정상인가요? 원본 0/23 → 현재 0단계: 정상인가요? 정답은 마지막 페이지에서 확인하세요.

합성 수량과 전체 저장

같은 수량을 두 번 더하지 않는 것이 중요해요.

01 알·탈것 합성 사진

해당 재화의 ‘합성 수량’ 영역에 합성 사진을 올립니다. ‘57 선택됨’이면 사진 선택 수량은 57입니다. 탈것 ‘388 선택됨’이면 388입니다. 화면에 보이는 카드 개수를 세는 방식이 아닙니다.

02 추가 수량 (+α)

사진의 ‘선택됨’에 포함되지 않은 합성 재료만 별도로 더합니다. 펫만 선택되어 알이 빠진 경우 등, 빠진 수량을 알고 있을 때 사용하세요. 예: 사진 57 + 포함되지 않은 3 = 합성 60개. 이미 선택된 재료는 다시 추가하지 않습니다.

03 네 종류 한 번에 저장

게임 닉네임을 입력하고 ‘전체 모아서 저장’을 사용하세요. 스킬 → 알 → 탈것 → 물약 탭을 순서대로 올립니다. 탭을 바꿔도 읽은 값은 유지됩니다. 전체 저장 내역이 4/4인지 확인한 뒤 본인 수정 비밀번호 6자 이상을 입력하고 ‘4종 재화 한 번에 저장’을 누릅니다.

04 저장 성공 확인

성공 안내와 클랜원 목록의 닉네임을 확인하세요. 닉네임을 누르면 네 종류의 수량, 레벨, 합성 내역과 사진을 볼 수 있습니다. ‘일부 항목 저장’에서는 빈칸이 미입력으로 저장되므로 기존 항목을 그대로 보존하는 방식으로 생각하지 마세요.

다시 인식·수정·오류 전달

틀린 결과를 그대로 저장하지 않아요.

01 인식 결과가 다를 때

현재 사진의 ‘이 사진 다시 인식’을 눌러 재시도하세요. 연습 화면에서는 일반 인식이 실패할 때 호환 인식을 선택합니다. 숫자가 표시되었다고 모두 정확한 것은 아니므로 소수점, k, 레벨, 0단계를 원본과 비교하세요.

02 저장한 내 재화 수정

클랜원 목록에서 내 닉네임을 누르고 ‘내 재화 수정하기’를 선택합니다. 다시 촬영한 사진을 올리고 결과를 확인한 뒤 처음 정했던 본인 수정 비밀번호로 저장합니다. 클랜장 비밀번호와는 별개입니다.

03 어떤 오류인가요?

IMG-01: 사진을 열지 못함 / IMG-02: 파일 형식 또는 용량 / OCR-01: 인식 기능 불러오기 / OCR-02: 숫자 영역 탐색 실패 / OCR-03: 영역의 숫자를 읽지 못함 / OCR-05: 인식 실행 오류 / SAVE-01: 저장 오류.

04 운영자에게 보낼 자료

문제가 난 원본 캡처, 사용한 재화 탭, 정상이어야 하는 값, 실제 표시된 값, ‘오류 정보 복사’ 내용을 함께 보내주세요. 예: 녹색 물약 원본 3.3k / 결과 33,000. 비밀번호나 클랜 입장 코드는 보내지 마세요.

연습 체크

정상 숫자처럼 보이지만 10배로 표시되는 오류도 있나요? ‘issues: []’여도 사진 비교는 필요할까요? 둘 다 그렇습니다.

클랜장 시작 안내와 정답

클랜별 초대 링크와 관리 정보를 구분해 보관해요.

01 새 클랜 만들기

클랜장 관리 화면에서 ‘새 클랜 만들기’를 선택합니다. 클랜 이름, 서버 번호, 클랜장 비밀번호 10자 이상을 입력합니다. 생성 후 클랜 ID와 관리 주소를 보관하고 클랜원에게는 초대 링크만 공유하세요.

02 기존 우리 클랜 연결

기존 기록이 있다면 ‘기존 클랜 연결’을 사용하세요. 기존 입장 코드와 새 클랜장 비밀번호로 연결합니다. 서버 번호 저장 기능이 비활성화라면 서비스 운영자가 구글 스크립트를 업데이트해야 합니다. 새 클랜을 만들어 기존 기록이 자동으로 옮겨진다고 생각하지 마세요.

03 서버 수정과 초대 링크 변경

클랜장 로그인 후 ‘클랜 서버 저장’으로 서버 번호를 수정할 수 있습니다. 같은 서버라도 서로 다른 클랜의 기록은 별도로 관리합니다. 초대 링크를 변경하면 이전 링크와 입장 코드는 무효가 되니 새 링크를 다시 공유하세요.

04 자율 후원

사이트의 ‘운영 후원’ 창에서 안내를 확인할 수 있습니다. 후원 방법은 운영자가 등록한 뒤 열립니다. 후원은 선택이며 이용 기능의 차이는 없습니다. 후원 창이 ‘준비 중’이라면 아직 결제나 송금 기능이 연결되지 않은 상태입니다.

연습 정답

3.3k → 33,000개는 오류, 올바른 환산은 약 3,300개입니다. 0/23의 현재 0단계는 정상입니다. 57 + 추가 3 = 합성 60개입니다. 물약만 입력하면 전체 4종 저장을 완료할 수 없습니다.
